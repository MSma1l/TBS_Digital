# Purpose

Implement the TBS Digital website according to the approved design mockups.

## Design Source

The provided design mockups are the primary source of truth.

Always:

- Match layout, spacing and hierarchy to the mockup.
- Match typography, colors and component sizes.
- Preserve responsive behaviour.
- Reuse existing project components whenever possible.

## Allowed Improvements

You may improve:

- accessibility;
- responsive behaviour;
- animations;
- performance;
- semantic HTML;
- code quality.

Do not change the visual concept without a clear reason.

## Implementation Rules

Before writing code:

1. Compare the existing page with the mockup.
2. Identify missing or changed UI.
3. Describe the implementation plan briefly.
4. Implement only the required changes.

## Coding Rules

- Do not rewrite unrelated code.
- Prefer modifying existing components.
- Avoid duplicate components.
- Keep components small and reusable.
- Follow the existing project architecture.
- Keep TypeScript strict.
- Preserve responsiveness.

## Priority

1. Match the approved design.
2. Maintain clean architecture.
3. Improve UX only when it does not conflict with the design.
